## 1. Executive Summary & Security Model

TripLine's backend is a Python 3.13 FastAPI application (`dashboard/app.py` & `dashboard/api.py`). It is the **sole authoritative source of truth** for agent planning, ArmorIQ policy authorization, in-MCP path-jail containment, egress canary inspection, witness hash-chains, and signed RFC 8785 incident receipts.

### 1.1 Global Security & Middleware Controls
1. **Mutation Size Limit:** Middleware in `dashboard/app.py:31–37` enforces a strict 64KB request body size limit on all `POST`, `PUT`, and `PATCH` mutations. Payloads exceeding 64KB are rejected immediately with `HTTP 413 Payload Too Large`.
2. **Security Headers:** Strict headers are injected on all HTTP responses:
   - `Content-Security-Policy: default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; img-src 'self' data:; media-src 'self';`
   - `X-Content-Type-Options: nosniff`
   - `X-Frame-Options: DENY`
   - `Referrer-Policy: no-referrer`
3. **CSRF Protection:** Mutation endpoints (`POST /api/agent/runs`, `POST /api/jobs`, etc.) enforce session-bound CSRF token validation (`X-CSRF-Token` header) and browser `Origin` header matching (`dashboard/security.py`).
4. **Secret Scrubbing:** All API payloads and job outputs pass through `sanitize_payload()` and `redact_secrets()`, ensuring raw API keys (`ak_live_*`, `AIzaSy*`, `sk-ant-*`, `sk-*`), private keys, and local absolute filesystem paths are scrubbed before reaching the client.
5. **Path Traversal Shield:** Identifiers in route parameters (`run_id`, `receipt_id`, `job_id`) are validated via `SAFE_ID_PATTERN = re.compile(r"^[A-Za-z0-9_.-]+$")`. Any attempt containing `..`, `/`, or `\` returns `HTTP 400 Bad Request`.

## 3. Required Implementation Rules for Phases 7 & 8

1. **Do Not Invent New Endpoints:** The 27 endpoints in this matrix provide complete coverage for the entire product experience. No new routes are needed.
2. **Preserve CSRF & Mutation Guardrails:** All mutations (`POST`, `PUT`, `DELETE`) from the frontend must include `X-CSRF-Token` retrieved from `GET /api/csrf-token`.
3. **Fail-Closed Presentation:** When `key_present` is false or `live_enabled` is false, the UI must display disabled launch buttons with clear explanations rather than faking execution.
