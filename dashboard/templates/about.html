About Tripline & ArmorIQ

Architecture responsibilities, boundaries, and honest limitations.

1. What is ArmorIQ's Job?

ArmorIQ acts as the authoritative upstream policy and identity gatekeeper. When an autonomous AI agent proposes invoking an MCP tool, ArmorIQ evaluates maintainer roles, session tokens, and tool permissions against centralized platform policies (such as cli-tripline-maintainer-tripline-mcp). Actions prohibited by policy—such as destructive branch deletions—are denied upstream at the platform perimeter before reaching the repository MCP server, ensuring 0 unwanted tool dispatches.

2. What is Tripline's Job?

Tripline acts as the downstream containment and forensic evidence engine. Because ArmorIQ authorizes tools broadly (e.g. allowing read_file or comment_issue for maintainers), Tripline inspects runtime arguments and execution parameters:

  • Path Containment Jail: Enforces userland open-then-verify file descriptor checks (fcntl(fd, F_GETPATH)) to stop path traversal and TOCTOU escapes.
  • Canary Egress Gateway: Quarantines outbound comments and payload bodies attempting to exfiltrate planted secrets.
  • Cryptographic Receipts: Emits canonical JSON SHA-256 receipts signed with HMAC bound to an append-only witness chain, proving exactly what happened.

3. Documented Limitations & Assumptions

Honesty is the product. As documented in docs/limitations.md:

  • Canary Encoding Residual: Tripline's egress scanner matches exact token substrings. It does not detect Base64-encoded, reversed, or fragmented secrets across multiple comments. Neither layer stops transformed egress.
  • Witness Locality: The witness HMAC key resides on the local filesystem (0o600 permissions). It defends against unverified tool execution, not against a fully compromised local host user.
  • Symmetric HMAC Signatures: Receipts use symmetric HMAC signatures rather than asymmetric public-key cryptography (e.g. Ed25519). Verification requires access to the shared signing key.
  • Model Refusal Independence: Layer defense protection is measured independently of LLM alignment or refusal rates.
