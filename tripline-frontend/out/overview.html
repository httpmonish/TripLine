// ARCHITECTURAL DIVISION OF RESPONSIBILITY

Authorize, Contain, and Prove.

ArmorIQ decides upstream policy intent. Tripline enforces in-MCP parameter containment and mints signed forensic receipts for every denied action.

1. Authorize (ArmorIQ)

Intent assurance at planner boundary: capture_plan, policy match, and token minting. Stops destructive actions upstream before they ever touch infrastructure.

// source:docs/ARCHITECTURE.md Sec. 2

2. Contain (Tripline)

In-MCP boundary protection: fstat descriptor inode verification blocks directory traversal, and exact-match canary scanners quarantine outbound comment exfiltration.

// source:mcp/common/jail.py & gateway/taint_rule.py

3. Prove (Witness & Receipt)

Local HMAC-chained witness ledger and Canonical JSON Incident Receipts. Guarantees 0-byte leaks and deterministic tamper detection offline via make verify.

// source:receipts/verify.py & .tripline/witness/
